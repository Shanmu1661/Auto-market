AutoMarket Template Documentation

AutoMarket is a premium, multipurpose HTML5/CSS3 template engineered specifically for the Used Car Market, Auto Dealerships, Vehicle Inspection Services, and Car Brokerages. Built strictly with standard web technologies (HTML, CSS, JavaScript, Bootstrap 5.3).

15+ Pages Included
Home, Inventory, Details, Dashboard, etc.
100% RTL & Dark Mode
Persistent dual toggles
WCAG 2.1 AA Compliant
Accessible and SEO-Ready

Color System & CSS Variables

To change the primary brand color across all pages, simply edit the CSS custom properties in assets/css/style.css: 

:root {
  --primary: #2563eb;          /* Main Royal Blue Accent */
  --primary-rgb: 37, 99, 235;
  --secondary: #f97316;        /* Automotive Orange */
  --accent: #10b981;           /* Inspection Green */
  --font-heading: 'Plus Jakarta Sans', sans-serif;
  --font-body: 'Inter', sans-serif;
}

Dark Mode & RTL Implementation

Dark mode and RTL are completely dynamic and persistent:

  • Theme Engine: Toggled by adding data-bs-theme="dark" and data-theme="dark" to the <html> element. System preferences are automatically detected via window.matchMedia and stored in localStorage.getItem('automarket_theme').
  • RTL Engine: Toggled by setting dir="rtl" on <html> and stored in localStorage.getItem('automarket_dir'). All margins, dropdown arrows, badges, and card orientations adapt automatically.

User Dashboard Architecture

The template features a dedicated User Dashboard (dashboard.html) with zero external frameworks required:

  • Profile Management: Edit personal name, email, phone, and delivery hubs with instant toast alert feedback.
  • Saved Vehicles (Wishlist): Synchronized with browser localStorage. Users can favorite any car and view/delete it from their dashboard.
  • Bookings & Order History: Shows upcoming test drives and passed 200-point inspection dossiers with download links.
  • Messages & Inquiries: Interactive simulated 2-way chat with dealership specialist.
